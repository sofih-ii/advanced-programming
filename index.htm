Conceptos Básicos: HTML y CSS

HTML y CSS son dos tecnologías complementarias que forman la base del desarrollo web moderno:

  • HTML = HyperText Markup Language
    Define la ESTRUCTURA y el CONTENIDO de la página
  • CSS = Cascading Style Sheets
    Define el ESTILO, COLORES y POSICIONAMIENTO

Analogía útil: Si HTML es el esqueleto de la página, CSS es la ropa y maquillaje que la hace hermosa.

Etiquetas HTML Más Importantes

Etiquetas de Texto

Estas etiquetas estructuran el contenido de texto:

<h1> a <h6>
Títulos y subtítulos (h1 es el más importante)
<p>
Párrafos de texto normal
<strong>
Texto importante (se ve en negrita)
<em>
Texto enfatizado (se ve en cursiva)
<br>
Salto de línea (sin necesidad de párrafo nuevo)

Etiquetas de Enlaces e Imágenes

<a href="url">
Crea un ENLACE o HIPERVÍNCULO a otra página
<img src="imagen.jpg">
Inserta una imagen en la página
<nav>
Define la sección de navegación (menú)

Etiquetas de Listas

<ul>
Lista sin orden (con viñetas •)
<ol>
Lista ordenada (con números: 1, 2, 3...)
<li>
Elemento dentro de una lista

Estructura Completa de una Página HTML

Este es un ejemplo de una página HTML válida y bien estructurada. Fíjate cómo cada etiqueta se abre y se cierra correctamente: 

<!DOCTYPE html>
<html lang="es">
    <head>
        <meta charset="UTF-8">
        <title>Mi Primera Página Web</title>
        <link rel="stylesheet" href="style.css">
    </head>
    <body>
        <h1>¡Hola, Mundo!</h1>
        <p>Esta es mi primera página web.</p>
    </body>
</html>

Explicación Línea por Línea:

  1. <!DOCTYPE html>
    Declara que este es un documento HTML5. Debe ser la PRIMERA línea.
  2. <html lang="es">
    Abre el documento HTML. lang="es" especifica idioma español.
  3. <head>
    Contiene información sobre la página (no visible en pantalla).
  4. <meta charset="UTF-8">
    Define la codificación de caracteres (acentos, ñ, etc.).
  5. <title>
    El título que aparece en la pestaña del navegador.
  6. <body>
    Inicia el contenido visible de la página.
  7. </body>
    Cierra el cuerpo. Todas las etiquetas abiertas deben cerrarse.
  8. </html>
    Cierra el documento HTML. Debe ser la ÚLTIMA línea.

¿Para Qué Sirve CSS?

CSS (Cascading Style Sheets) es lo que hace que las páginas web se vean hermosas y profesionales.

Cosas que puedes hacer con CSS:

  • ✓ Cambiar colores de texto y fondos
  • ✓ Ajustar tamaños de fuentes
  • ✓ Crear espacios (márgenes y rellenos)
  • ✓ Hacer diseños complejos (flexbox, grid)
  • ✓ Crear animaciones y transiciones suaves
  • ✓ Hacer que los sitios sean responsivos (móvil, tablet, desktop)
  • ✓ Cambiar posiciones y tamaños de elementos

En próximas lecciones aprenderemos cómo escribir CSS efectivo y moderno.

Elementos Avanzados de HTML

Ahora veremos elementos HTML más estructurados y complejos que se usan para organizar información de forma profesional y accesible.

Listas HTML: Organizando Información

Las listas son formas de organizar información de manera ordenada y legible. HTML tiene dos tipos principales de listas:

Listas Sin Orden (Desordenadas)

Se usan cuando el orden de los elementos NO importa. Los elementos aparecen con viñetas (•)

Ejemplo de lista sin orden:
  • item 1 - Primer elemento de la lista
  • item 2 - Segundo elemento
  • item 3 - Tercer elemento

Código HTML:

<ul>
  <li>item 1</li>
  <li>item 2</li>
  <li>item 3</li>
</ul>

Listas Ordenadas (Numeradas)

Se usan cuando el orden SÍ importa. Los elementos aparecen numerados (1, 2, 3...)

Ejemplo de lista ordenada:
  1. item 1 - Primer paso
  2. item 2 - Segundo paso
  3. item 3 - Tercer paso

Código HTML:

<ol>
  <li>item 1</li>
  <li>item 2</li>
  <li>item 3</li>
</ol>

Diferencia clave: Usa <ul> para listas de compras, características, etc. Usa <ol> para pasos, rankings, instrucciones.

Elementos Multimedia: Imágenes y Videos

HTML5 permite insertar imágenes y videos directamente en la página sin necesitar plugins externos. Esto mejora la experiencia del usuario.

Imágenes (<img>)

La etiqueta <img> inserta una imagen en la página.
Atributos importantes:

  • src = ruta de la imagen (obligatorio)
  • alt = texto alternativo si la imagen no carga (obligatorio)
  • width y height = ancho y alto de la imagen
  • loading="lazy" = carga la imagen solo cuando se necesita (optimización)
Ejemplo de imagen:

Código HTML:

<img src="imagen.jpg" alt="Descripción" width="300" height="200" loading="lazy">

Videos (<video>)

La etiqueta <video> permite reproducir videos sin depender de YouTube.
Atributos importantes:

  • width y height = tamaño del reproductor
  • controls = añade botones de play, pausa, volumen
  • autoplay = inicia automáticamente (no recomendado)
  • <source> = especifica el archivo de video
Ejemplo de video:

Código HTML:

<video width="320" height="240" controls>
  <source src="video.mp4" type="video/mp4">
  Tu navegador no soporta video.
</video>

Tablas: Organizando Datos en Filas y Columnas

Las tablas (<table>) se usan para mostrar datos organizados en filas (horizontales) y columnas (verticales).

Estructura básica de una tabla:

  • <table> = contenedor de la tabla completa
  • <tr> = table row (una fila)
  • <th> = table header (encabezado de columna, en negrita)
  • <td> = table data (una celda de datos)
  • <thead> = agrupa los encabezados
  • <tbody> = agrupa el contenido de la tabla
Ejemplo de tabla simple:
Nombre Edad
Ana 25
Carlos 30

Código HTML:

<table>
  <thead>
    <tr>
      <th>Nombre</th>
      <th>Edad</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Ana</td>
      <td>25</td>
    </tr>
  </tbody>
</table>

Nota: Aunque puedes crear diseños con tablas, hoy en día se recomienda usar CSS (flexbox, grid) para layouts. Las tablas deben usarse SOLO para datos tabulares.

Formularios: Recolectando Información de Usuarios

Los formularios (<form>) permiten que los usuarios envíen información al servidor. Son fundamentales para:

  • Contacto (nombre, email, mensaje)
  • Logins (usuario y contraseña)
  • Búsquedas
  • Registros o inscripciones

Elementos principales de formularios:

  • <form> = contenedor del formulario
  • <label> = etiqueta descriptiva (importante para accesibilidad)
  • <input> = campo de entrada (texto, email, contraseña, etc.)
  • <textarea> = área grande de texto
  • <select> = lista desplegable
  • <button> o <input type="submit"> = botón de envío
Ejemplo de formulario de contacto:





Código HTML:

<form action="/submit" method="post">
  <label for="name">Nombre:</label>
  <input type="text" id="name" name="name">
  
  <label for="email">Email:</label>
  <input type="email" id="email" name="email">
  
  <input type="submit" value="Enviar">
</form>

Tipos de Input Más Comunes:

type="text"
Campo de texto normal (una línea)
type="email"
Campo que valida email (muestra teclado de email en móviles)
type="password"
Campo que oculta lo que escribes con puntos
type="number"
Campo solo para números (con botones +/-)
type="checkbox"
Casilla que se puede marcar (sí/no)
type="radio"
Botón de opción (solo puedes elegir una opción)
type="submit"
Botón para enviar el formulario

Botones: Elementos Interactivos

Los botones (<button>) son elementos interactivos que permiten a los usuarios realizar acciones como enviar formularios, activar funciones, o navegar a otras páginas.

¿Para qué se usan los botones?

  • Enviar formularios
  • Activar funciones JavaScript
  • Mostrar alertas o mensajes
  • Iniciar descargas
  • Navegar a otras páginas
  • Cambiar el contenido de la página dinámicamente

Tipos de Botones HTML

type="button"
Botón genérico que NO envía formulario. Se usa para acciones personalizadas
type="submit"
Botón que envía el formulario al servidor
type="reset"
Botón que limpia todos los datos del formulario

Ejemplo 1: Botón Simple con Alerta

Este botón ejecuta una función JavaScript que muestra un mensaje:

Código HTML:

<button type="button" onclick="alert('¡Hola!')">
  Haz clic aquí
</button>

Ejemplo 2: Botón para Enviar Formulario

Los botones dentro de un <form> pueden enviar datos:




Código HTML:

<form>
  <label for="email">Email:</label>
  <input type="email" id="email" name="email">
  
  <button type="submit">Enviar</button>
</form>

Ejemplo 3: Botón Reset para Limpiar Formulario

El tipo reset borra todos los datos ingresados:




Código HTML:

<button type="reset">Limpiar Formulario</button>

Atributos Importantes de Botones

type
Define el tipo de botón (button, submit, reset)
onclick
Ejecuta código JavaScript cuando se hace clic
disabled
Desactiva el botón (aparece gris y no se puede hacer clic)
name
Nombre para identificar el botón en un formulario
value
Valor que se envía cuando se hace clic (en formularios)
class
Clase CSS para aplicar estilos personalizados

Ejemplo 4: Botón Desactivado

El atributo disabled desactiva un botón:

Código HTML:

<button type="button" disabled>
  Botón Desactivado
</button>

Diferencia: <button> vs <input type="button">

Aunque ambos crean botones, <button> es más moderno y flexible:

<button>
Más flexible, puede contener HTML (iconos, emojis, etc.)
<input type="button">
Más básico, solo texto plano. Usado en formularios clásicos
